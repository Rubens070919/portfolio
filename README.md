## Projetos

### 1. AlugaPerto - Marketplace de Aluguel de Equipamentos

Aplicativo de aluguel de equipamentos entre pessoas (peer-to-peer), lancado em producao na Google Play.

- Stack: React Native / Expo Router, Firebase (Auth, Firestore, Storage, Functions), backend Node.js na Railway
- Funcionalidades: cadastro de equipamentos em wizard de 3 etapas, sistema de avaliacao bidirecional, chat em tempo real, notificacoes push
- Pagamentos: integracao com modelo de pre-autorizacao (caucao) e regras de seguranca do banco de dados
- Estruturacao juridica do produto: termos de uso, politica de privacidade, contrato eletronico e registro de marca

### 2. Dashboards de BI para Operacao Industrial

Desenvolvimento e manutencao de dashboards de Power BI para operacoes de moagem de cana-de-acucar em tres unidades industriais.

- Medidas DAX complexas (ajustes de fuso horario, logica de metas proporcionais, indicadores de status por cores)
- Modelagem de dados com Power Query
- Analise de views SQL Oracle
- Desenvolvimento de modelos dbt (camadas staging e marts)
- Scripts de ETL em PySpark
- Entregaveis: boletim de moagem com pagina de recordes historicos, relatorio de performance de colhedoras, painel de frota/equipamentos

### 3. Sistema de Gestao para Igreja

Aplicativo de gestao para uma igreja de aproximadamente 200 membros organizados em 7 Grupos de Crescimento (GCs).

- Pesquisa e validacao de mercado com framework estruturado de seis etapas
- Definicao de escopo de MVP com o cliente
- Fase 1: controle financeiro (dizimos, ofertas, despesas) e registro de atas de culto
- Escopo completo: cadastro de membros, gestao de GCs, mural de avisos, aniversariantes, modulo infantil e dashboard gerencial

### 4. Validacao de SaaS para Gestao de Eventos e Parceiros

Pesquisa e validacao de mercado para uma ideia de SaaS voltado a organizacao de eventos, com foco em controle de pagamentos entre organizador e parceiros/expositores.

- Levantamento de mercado identificando baixa concorrencia direta no nicho
- Estrategia de validacao (dor real vs. hipotese) e decisao de lancamento fechado antes de abertura publica
- Planejamento de arquitetura de banco de dados multi-tenant desde a primeira etapa

### 5. App de Consulta de Pedagios Free Flow

Planejamento de um aplicativo para consulta de passagens em pedagios free flow no Brasil via placa do veiculo, verificando cobrancas pendentes.

- Arquitetura MVP definida: React Native/Expo no front-end, backend Node.js na Railway
- Integracao com API agregadora de concessionarias (autenticacao HMAC-SHA256, webhooks)
- Diferencial de produto proposto: notificacoes push proativas para cobrancas pendentes
